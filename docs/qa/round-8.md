## 3. 止める理由

Round 8 の A 項目 5 件は、いずれも実装の磨きでは閉じない:

| # | 内容 | 必要なこと |
|---|---|---|
| A1 | カテゴリページが 2 万 px の単一スクロール | 設計変更（折りたたみ／分割）→ `remaining.md` R4 |
| A2 | 操作前が空のステージ（Toast、Cursor follower、Hover、Confetti、Command palette） | デモ個別の「初期状態の見本」設計。コマンドパレットは開いた状態にするとフォーカストラップでキーボード導線が壊れた（Round 6） |
| A3 | Perf 86〜89 / TBT 400〜540ms / LCP 2.0〜2.4s | `remaining.md` R1・R2（LCP は見出しフォント到着で決まる。予算の扱いの判断待ち） |
| A4 | カテゴリ色がページににじまない | 色相は反映されていた（`--tint-hue` 110 / 250 を確認）が、不透明度 0.08〜0.1 では静止画で読み取れない → 0.14 に上げた（最終コミット） |
| A5 | プレースホルダー本文（「段落 1〜6」）、重複デモ | デモの文言と、`aliasOf` の扱い（D8 どおり「共通」と明示している） |

B 項目のうち実装で対応したもの: パンくず「›」、カード下部の位置、目的ページの行、390 の統計ラベル。残り（390 の和文改行の孤字、詳細ページのグリッド幅、X-ray のカウント表記、404 の下半分、⌘K プレビューの縮小）は `remaining.md` に引き継ぐ。
