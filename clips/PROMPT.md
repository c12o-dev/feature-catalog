# 台本の書き方（draft.mjs が AI に渡す仕様）

feature-catalog の 1 パターンを、X 向けの 6〜12 秒の無音デモ動画にする。
あなたの仕事は「何を操作して何を見せるか」の台本を JSON で 1 つ書くこと。録画・切り出し・字幕は機械がやる。

## 出力

JSON だけを出力する。前後に説明文やコードフェンスを付けない。

```
{
  "slug": "<slug>",
  "crop": "demo" | "content" | "viewport",
  "pad": 28,
  "extend": { "bottom": 240 },        // 任意。切り出し範囲を広げる（動画画素）。トースト等を含めたいとき
  "toaster": "near-demo",            // 任意。sonner のトーストをデモ直下に寄せる。toast を出すデモだけ
  "steps": [ ... ],
  "post": { "ja": "...", "en": "..." }
}
```

- `crop`: デモが領域いっぱいに広がるなら `demo`。中身が小さく中央に寄っている（max-w-sm など）なら `content`。画面全体が要るときだけ `viewport`。
- `steps` は上から順に実行される。1 要素に 1 操作だけ。
  - `{ "mark": "テロップ" }` — ここからテロップを表示（次の mark まで）。1〜24 文字。1 本の動画で 2〜3 本
  - `{ "click": { "role": "button", "name": "Success" } }` — role と name で要素を指定（name は `/正規表現/` 可）。`"text"`、`"label"`、`"selector"` も使える。既定はデモ領域内から探す。トーストなど領域外は `"scope": "page"`
  - `{ "hover": { ... } }` — click と同じ指定で、押さずにカーソルを乗せる
  - `{ "type": "設定", "delay": 160 }` — キー入力。delay は 1 文字ごとの ms
  - `{ "press": "Enter" }` — キー 1 つ（Enter, Escape, Tab, ArrowDown, Control+k など）
  - `{ "wait": 900 }` — 待つ（ms）。アニメーションや自動遷移を見せるときに
  - `{ "scroll": 300 }` — デモ内でホイール（px）
- 要素指定はデモのソースに実際にある aria-label / テキスト / role を使う。推測で名前を作らない。
- 操作は 3〜5 手。最初の mark の前に操作を置かない。最後は結果が見える状態で 1,200〜1,800ms 待って終える。
- テロップは「何が起きているか」ではなく「なぜそうするか」を短く。例: 「作業を止めずに結果だけ伝える」「6 桁そろった瞬間に判定」。体言止めか短い文。句点なし。
- `post.ja` は X の本文（140 文字以内、URL なし、ハッシュタグなし、絵文字は 0〜1 個）。1 行目で見せ場、2 行目で一言。jh3yy 風に短く、小文字の気楽さで。`post.en` は同じ内容の英語 1〜2 文（小文字、ピリオド控えめ）。
- デモ内の表示や文言は、ソースにあるものだけを根拠にする。
